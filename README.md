# M5Stack Tab5 Examples
Programming examples for the M5Stack Tab5.

# Requirements

In the Arduino IDE Boards Manager, ensure that you are using the M5Stack Board Manager (version 3.2.2 or higher) with the M5Tab5 board selected. Also, install the M5Unified and M5GFX libraries.

# Using the examples

Each example is an independent Arduino sketch in `src/<name>/<name>.ino`. Open the `.ino` file for the example you want to use in the Arduino IDE; do not compile all the examples together. The `FullTest` example also requires the LVGL library. `Movement` is an empty sketch template because its original source file contained no code.
